# STUDYCYCLE

### Student-to-Student Book & Equipment Exchange System

STUDYCYCLE is a web application that helps students buy, sell, and exchange academic books and equipment with other students.

## Features
- Student login and registration
- Create, edit, and delete listings
- Browse available listings
- Update listing status
- Upload listing images
- View personal listings
- Store listing data in MongoDB

## Technologies Used
- React
- Vite
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Run Locally

### Frontend
1. Open the project folder in a terminal.
2. Install dependencies:
   `npm install`
3. Start the frontend:
   `npm run dev`

### Backend
1. Open the `server` folder in a separate terminal.
2. Install dependencies:
   `npm install`
3. Create a `.env` file in the `server` folder and add your MongoDB connection string.
4. Start the backend:
   `node server.js`

## Environment Variables
Keep your database connection details private. Do not upload your `.env` file to GitHub.

## Project Status
